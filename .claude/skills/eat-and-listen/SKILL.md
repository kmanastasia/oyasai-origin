## 便箋（この順に読まれます）

- `eat`（食べ方）：まず届けたいこと。食べ方の項目と、そのすぐ後ろに味ことば。生のことから、火を通すことへ。
- `wish`（想い）：農家の想い・メッセージ。人の話、食べる人へ向けた言葉、育て方に込めた気持ち（「農薬を使わずに育てています」のような一言）。
- `grow`（育て方・こだわり）：具体的な育て方、技、判断とその理由、土地のこと。

## 割り当ての作法

1. 3枚すべてに `eat` `wish` `grow` の順で1回ずつ出力します。
2. `land_entry_ids` は空にします（書き出しは置かず、土地の話は `grow` に入れます）。
3. `card_teaser_entry_id` には一覧のカードと表紙に出す一言を、`disclosure` が `public` の項目から1つ選びます。食べ方の項目があればそれを最優先にします（例：「まずは生で、皮ごとかじってみてください」）。`public` の項目がなければ null です。
4. 1枚は3〜5項目に抑えます。読み上げで1枚30〜60秒に収まる量です。
5. 同じ id を2回使いません。渡されていない id を作りません。
6. 味ことばの項目は、同じ食べ方の項目のすぐ後ろに置きます。
