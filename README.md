# OYASAI ORIGIN（仮）

**日本のお野菜を世界へ。** 畑から、未来の人への手紙。
*Japanese vegetables, to the world. A letter from the field, to someone in the future.*

農家の話を本人の言葉のまま「手紙」として残し、食べる人が手軽に選んで、読んで、聴けるようにするサービスです。

> 登場する農家・町は架空です。価格はすべて仮で、購入や送信は行われません。読み上げは合成音声で、本人の声ではありません。

## ① 誰の・どんな課題か

おやさい旅で会ってきた農家さんたち。畑で重ねてきた判断は、書き残さないまま本人が畑を離れると消えてしまいます。

基幹的農業従事者は 103.6 万人、平均 67.7 歳（2025 年、農林水産省 令和 7 年度 食料・農業・農村白書）。

だから、本人が畑にいるうちに、本人の言葉のまま残して、お野菜に添えて食べる人に届けます。

| 画面 | 誰が | すること |
|---|---|---|
| ① 残す `/keep` | 運営者 | 聞き取りを貼ると、Claude が技・判断・土地・人に分ける。語られていない理由は補わず、次の質問にする |
| ② 封をする `/seal` | 農家（運営者が代理可） | タップだけで「はい／ちがう／残すだけ（外に出さない）」を選んで封をする |
| ③ えらぶ `/choose` | 食べる人 | 届いている手紙を選ぶ（JP／EN） |
| ④ 手紙 `/letter` | 食べる人 | 一口ずつ開いて、読む・聴く。国内は「受け取る」、海外は「訪ねる」で結ぶ（JP／EN） |

## ② 3分で試せる始め方

Node.js 22.9 以上が必要です。

```bash
npm install
```

```bash
npm run dev
```

http://localhost:3000/keep を開いて、次の順に押します。

1. 「聞き取りの見本を入れる」→「手紙の下書きにする」
2. 「作り手に見せる」→ 1 枚ずつ答える。どれかを「残すだけ」にすると、③④から消えることを確かめられます
3. 「封をする」→「届いている手紙を見る」→「この手紙を開く」
4. 右上の JP｜EN で切り替えると、結びが「受け取る」から「訪ねる」に変わります

**API キーがなくても最後まで動きます**（同梱の保存データを使います）。API キーがあっても通信せず、保存データだけで同じ流れを試すときは `npm run demo` で起動します。自分の聞き取りを Claude で分けるには、プロジェクト直下に `.env` を作って `ANTHROPIC_API_KEY=（あなたの鍵）` と書き、`npm run dev` を起動し直してください。

```bash
npm test
```

```bash
npm run verify
```

本番の文字起こしに差し替えるときは、`data/transcript.md` を書き換えて、保存データを作り直します（API キーが必要）。

```bash
npm run generate
```

読み上げで目立つ読み違いがあれば、`data/speech.json` の `skip_speech_ids` に項目 id を書くと、その項目だけ読まなくなります（原文は変えません）。

## ③ Claude の機能の使い分け

| 機能 | 何に使うか | 置き場所 |
|---|---|---|
| Skills | 聞き手の作法：`farm-archive`（残す）、`eat-and-listen`（手紙）。アプリが実行時に読み込むので、作法の置き場所は1つだけ | `.claude/skills/` |
| Structured outputs | Claude の出力の形を JSON Schema で固定 | `schemas/` |
| フック | `git commit` の前に `npm run verify` を走らせ、失敗したら止める。農家の言葉を守る約束を、人の注意ではなく仕組みにする | `.claude/settings.json`、`.claude/hooks/` |
| サブエージェント | `label-checker`：架空・見本・合成音声・Translated by Claude・仮の表示と、英訳に足された理由・主語・感情を点検する。読むだけ | `.claude/agents/label-checker.md` |
| MCP | 使わない。外部につなぐ必要がないため | — |

Claude がするのは、分類・段落番号の割り当て・英訳だけです。本文・方言・土地の歴史は書かせません。Structured outputs と Citations は同時に使えないので、原文との照合はコードで行います（`lib/verbatim.mjs`）。一字でも違う引用は落とし、落とした件数も画面に出します。読み上げはブラウザ標準の機能が原文をそのまま読むだけで、Claude は関わりません。

アプリの API 呼び出しはすべて `claude-opus-5-5`。effort は分類が `high`、割り当てと英訳が `medium`。`stop_reason` を確かめ、断られたときは server-side fallbacks に任せます。通信が落ちたら 1 回だけ再試行し、だめなら `data/replay/` の保存データを使います。

`npm run verify` が確かめること：quote・reason_quote の一字一句一致／理由がない判断の質問／archive_only の流出 0 件（どの項目を残すだけにしても出ないことを、全項目で試す）／英語訳の漏れ 0 件／必須の表示／送信・決済・録音・外部音声のコードがないこと／`private/`・`.env` が git に追跡されていないこと。

## ④ 試行錯誤の経緯

- **v1 円環暦**：語りで畑の一年を染める暦。見た目は強いが、何のために残すのかが弱かった
- **v2 コーヒー**：野菜をスペシャルティコーヒーのように見せるラベルと味のホイール。「かっこいい」が、残す目的から離れた
- **v3 残す×受け取る×買う**：農家が残し、食べる人が受け取り、買える流れに。画面と言葉が増えて重くなった
- **v4 手紙**：「未来の人への手紙」に一本化。ホイールを捨てて、手軽に選べて手軽に聴ける形にし、JP／EN と「訪ねる」を足した
