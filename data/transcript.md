# 【仮】聞き取りの文字起こし（見本）
# 開発用の見本です。実在の人の発言ではありません。本番の文字起こしに差し替えます。
# 農家・農園・町の名前は仮の値です。

聞き手：この土地と、畑のことを教えてください。
みなみ：ここは山あいで、朝は霧が下りて、昼ごろまで晴れません。寒い土地ですが、この寒さがにんじんを甘くしてくれます。畑は親から引き継いで二十年になります。

聞き手：畑で、いちばん大事にしていることは何ですか。
みなみ：土を急がせないことです。収穫のあとは、すぐに次を植えずに、ひと冬、土を休ませます。肥料は堆肥だけで、化学肥料は使いません。種は指二本ぶん、間を空けて落とします。

聞き手：収穫の時期は、どうやって決めていますか。
みなみ：霜が降りるまで抜きません。霜に当たると、にんじんの中のでんぷんが糖に変わって、ぐっと甘くなるからです。葉の先が丸まってきたら、水やりを止めます。

聞き手：おすすめの食べ方を教えてください。
みなみ：まずは生で、皮ごとかじってみてください。ぽりぽりしていて、香りがいいです。火を通すなら、弱火でゆっくり。オリーブオイルと塩だけで焼くと、とろりとして、甘みが一番よく出ます。葉も捨てないで、刻んでかき揚げにするとおいしいですよ。

聞き手：この手紙を受け取る人に、伝えたいことはありますか。
みなみ：遠くの国で、このにんじんを食べてくれている人がいると思うと、それだけで畑に出る力になります。ひと口かじったときに、この山の朝の霧と、冬の寒さを、少しでも感じてもらえたらうれしいです。ありがとう。
